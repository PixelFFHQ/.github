# PixelFF

### Pixel Forge Foundry

**We make useful things.**

PixelFF is an independent creative workshop for software, browser tools, maker utilities, 3D printing projects, and other things built to solve real problems without unnecessary baggage.

## What we build around

- 🔒 Local-first design where it makes sense
- 🧰 User ownership and control
- 🛡️ Minimal permissions
- 💡 Understandable software
- ⚙️ Practical tools over feature bloat
- 🎨 Creative experimentation
